# Stage 3 設計: 関節（肘・膝）の再現

作成: 2026-11-24 / 前提: Stage 2 の基盤（カスタムエンティティ + プロパティ同期、docs/stage2-prototype-design.md）
目的: 上腕/前腕・大腿/脛の2セグメント構造で肘・膝の曲がりを統合版に再現する。本書は設計と計算仕様まで。実装は Stage 2 のパイプライン（S2-0〜S2-2）完成後。

## 入力データ（VSE メタデータ）

- 肘・膝の位置が直接取れる: `rightelbow.pos` / `leftelbow.pos` / `rightknee.pos` / `leftknee.pos`（Location）
- 手・足: `righthand.pos` / `lefthand.pos` / `rightfoot.pos` / `leftfoot.pos`
- 肩・股関節: Stage 1 と同じ導出（肩 = head.pos の約0.32m下から左右、股関節 = waist 基準）
- 注意: 肘・膝パートの有効条件は VSE の FBT モードに依存する（S2-3 で実地確認）。取れない場合は Stage 1/2 の1セグメント近似にフォールバックする

## 計算仕様（2セグメント分解）

腕を例にする（脚も同形: 肩→股関節、肘→膝、手→足に読み替え）。

1. 点列: S（肩）、E（肘）、H（手）のワールド座標
2. 方向: 上腕 `du = normalize(E − S)`、前腕 `df = normalize(H − E)`
3. 上腕ボーンの回転 `R_u`: 静止方向（真下 (0,−1,0)）を `du` に向ける回転。体のローカル座標系（bodyYaw 基準）で計算する
4. 前腕ボーンの回転は**親（上腕）からの相対回転**で送る: `R_f_rel = R_u⁻¹ · R_f`（`R_f` は静止方向を `df` に向ける回転）
5. 回転の表現変換: サーバー側では行列（またはクォータニオン）で合成・逆変換を行い、最後に Bedrock 側の Euler（合成順は S2-1/2 で実測確定）に変換してプロパティへ流す。Euler のまま合成しない（Stage 1 の近似式は1セグメント専用）
6. **ツイストの決定方針（2026-11-24 レビューで改訂）**: 静止方向「真下」からの最短弧は、腕を真上に上げた姿勢（180°）で回転軸が不定になりツイストが跳ぶ（VR では頻出姿勢）。対策として次を採る
   - 基本は**前フレームの回転からの最短弧**で連続性を保ち、基準へ緩く戻す
   - 併せて肘平面（肩→肘→手のなす面）の法線、または VSE の `.rot` でツイストを決める方法も候補とする。腕が伸びきると肘平面が不定になるため、その場合は前フレーム維持か `.rot` にフォールバック
   - クォータニオンは q と -q が同じ回転のため、Euler 変換の前に前フレームとの内積で符号をそろえる（符号連続性）
7. **解剖学的クランプ**: 肘の屈曲角 = du と df のなす角。前腕の相対回転が異常値（例: 屈曲 0〜160° の範囲外）になったらクランプし、メタデータのノイズで腕が反転しないようにする。膝も同様（後方への反り防止）。**伸びきり付近（屈曲角が小さい領域）はノイズが出やすいためデッドゾーンを持たせる**
8. **座標系と演算順序の規約**: R_u・R_f は体フレーム基準、ボーンのレスト方向は -Y で統一する。相対回転はクォータニオンで `R_u.conjugate().multiply(R_f)` とする
9. **unwrap とクランプの順序**: unwrap が直せるのは ±180° の巻き戻しのみで、ジンバルロック（中間軸 ±90°）の不連続は直せない。そのため Euler 分解順は、特異点が腕・脚で到達しにくい姿勢に来る順序を選ぶ（S2-1/2 で確定）。クランプ境界で ±180° の折り返しが起きないよう、単位（度）と範囲を実装時に明示する

- 更新頻度は Stage 2 と同じ 10Hz 目標（負荷実測は S2-2 の結果を引き継ぐ）

## フォールバック

- 肘・膝メタデータが無いプレイヤー/モードでは、前腕・脛の相対回転を 0 にし、Stage 2 の1セグメント表示に自動で落ちる
- パック未適用の統合版には Stage 1 の防具立て表示が残る（Stage 2 仕様どおり併走）
- **脚の歩行スイング代用（2026-11-25 本人指摘で追加）**: 足・膝メタデータが無いプレイヤー（非FBT。本人を含む）では、大腿・脛を歩行スイングで代用する。水平移動速度からバニラ準拠の limb swing を生成する: 位相は移動距離で進め、振幅は速度でスケールし、左右は逆位相。静止時はスイング角 0 へ減衰して両脚まっすぐ立つ。脛には大腿のスイングに連動した簡易屈曲（前に振る局面で軽く曲げる）を付ける。しゃがみ・ジャンプ等の再現は対象外（データ自体が無いため）
- FBT プレイヤーでは実データを優先し、スイング代用は使わない。切り替えは足・膝メタデータの有無で自動判定する。Stage 1 の防具立て脚ポーズにも同じスイングを適用する
