## 優先：S2-3 より先に固める指摘
- [ ] 指摘1（重大度・高）非FBTでは肘も waist も無い矛盾。腕にも簡易2ボーンIK代用（頭・手・bodyYawから肘を斜め後方・外側に逃がす）か、FBT専用と明記か。waist が無い場合の股関節基準（player位置または head.pos の垂直投影＋高さオフセット）も明記。
- [ ] 指摘2（高）歩行スイングの前提破綻：騎乗・滑空・飛行・遊泳・落下／ジャンプ中は振幅0へ。振幅は上限1.0でクランプ。1フレームの水平移動が 2.0m 超ならテレポートとみなして位相加算スキップ。
- [ ] 指摘6（高）トラッキング瞬断のチャタリング：S2-3でVSEのロスト時出力（null／ゼロ／固定値）を確認。「両足＋両膝が全て有効な場合のみFBT実データ」と一括判定。切替にヒステリシス（欠損0.5秒で代用へ、安定0.3秒で復帰）と 0.2〜0.3秒のクロスフェードを入れる。
- [ ] 指摘7（高）10Hz同期のエイリアシングと unwrap 発散：Q2の判断に直結。10Hz維持なら角速度上限の明記が妥協点。unwrap は無制限累積をやめ、静止・周期境界でリセットか ±180°正規化＋クライアント側最短補間へ。

## 設計文言として採用する指摘
- [ ] 指摘3（中）デッドゾーン（水平速度 <0.15 m/s は振幅0）と dt 依存の指数平滑化（減衰が更新周期に依存しない式）。VRの微小揺らぎ対策。移動量の参照元を胴体基準点に統一。
- [ ] 指摘4（中）脛の簡易屈曲を位相の連続関数で定義（例：大腿角 amp*A*sin(phase) なら脛は amp*B*max(0, cos(phase))）。amp→0 で自動的に 0°へ。
- [ ] 指摘5（中）スイング生成を共通ジェネレータ（大腿角＋脛屈曲角を返す）に分離。Stage 1 は大腿角のみを防具立てのピッチ軸へ、Stage 2 は両方をBedrockボーンへ。
- [ ] 指摘8（中）ツイスト決定を優先度付きルールに：屈曲 15°以上は肘平面の法線（du × df）で直接決定、伸びきり付近のみ前フレーム維持＋体幹基準への緩やかな減衰へ。
- [ ] 指摘9（中）クランプ後の再構築手順を明記（θ'=clamp(θ,0°,160°) で df を再生成してから R_f を計算）。デッドゾーン（0〜15°）は角度をスナップせず、法線のブレンド率だけを落とす領域と定義。
- [ ] 指摘10（低）肩オフセット：head.pos から約0.32m下をやめ、首の付け根（頭向き依存のローカル下方オフセット）から bodyYaw 基準で左右 ±0.18m とする。お辞儀時の肩の飛び出し対策。
